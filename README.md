# Laboura website

Static website for Laboura: jobs near home for job seekers, and verified staff for businesses, across 8 states of India.

- Plain HTML, CSS and JavaScript. No build step.
- Deploy on Vercel as a static site (framework preset: Other, no build command, output directory: root).

Before launch, replace the placeholders in square brackets, for example `[Registered company name]`, the toll-free number `1800-XXX-XXXX` and the WhatsApp number `+91 XXXXX XXXXX`.
